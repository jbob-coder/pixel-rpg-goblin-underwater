# Visual Reference Spec — Work District Support

Status: READY FOR REFERENCE GENERATION  
Building blueprint:
`../BLD_04_WORK_DISTRICT_SUPPORT.md`

## Scope

Covers:
- Work Storage
- Work Canopy

## Work Storage geometry

Target:
- footprint 7×6 m
- one story
- west-facing doorway
- compact utilitarian silhouette

## Work Canopy geometry

Target:
- footprint 7×6 m
- mostly open-sided
- roof supported by 4–6 posts
- no sealed-wall language

## Visual identity

Target:
- practical production support
- rougher than residences
- less dominant than smith
- visibly connected to tools/material handling

Avoid:
- warehouse scale
- factory/industrial-modern language
- cyberpunk machinery

## Material language

- heavy timber
- stone/packed-earth base
- dark metal hardware
- muted cloth/tarp accents
- reused settlement shingles/roof language

## Work Storage facade

Must show:
- one clear loading/service doorway
- simple window or vent
- material/rack identity
- cart/loading space

## Work Canopy

Must show:
- open access
- worktable
- material racks
- ore/wood staging
- readable support posts

## Modular parts

- wall panel
- loading-door panel
- corner posts
- simple roof modules
- rack modules
- workbench
- canopy posts
- canopy roof
- crate/material sockets

## Generation prompt specification

Create an original compact frontier work-district support reference sheet for a first-person pixel-styled real-3D RPG. Include two compatible structures: a 7×6 m utility storage building with a clear west-facing loading doorway, and a 7×6 m open-sided work canopy supported by simple timber posts. Use heavy timber, stone/packed-earth foundations, muted shingles, dark metal hardware, practical tool/material racks, ore/wood piles and worktables. Keep forms compact and mobile-friendly, not modern industrial, not ornate. Show front/side/rear/top/3-4 views plus modular parts and a simple storage interior cutaway. Neutral reference background, original IP, no watermark.

## Review checklist

- storage clearly enterable
- canopy clearly open
- smith remains visually more important
- material handling identity obvious
- modular parts reusable
