# Visual Reference Spec — Residence Type A

Status: READY FOR REFERENCE GENERATION  
Building blueprint:
`../BLD_02_RESIDENCE_TYPE_A.md`

## Geometry constraints

Target:
- 7×5.5 m footprint
- wall height about 3.2 m
- ridge about 4.8–5.4 m
- east-facing doorway
- doorway about 1.6×2.3 m

## Role

Reusable compact home for local NPCs.

The same structural contract should support at least two visually distinct houses.

## Visual identity

Target:
- practical frontier home
- modest
- warm but not decorative-heavy
- believable beside Community Hall and Smith
- original IP

Avoid:
- tiny fantasy cottage caricature
- mansion
- modern suburban house
- excessive chimney/roof complexity

## Base silhouette

Preferred:
- rectangular single-story body
- simple pitched roof
- small facade asymmetry
- optional tiny awning

## Variant system

The reference sheet should show at least two compatible facade variants using the same footprint.

Variant changes may include:
- window position
- roof material tint
- beam arrangement
- tiny awning
- chimney yes/no
- yard prop arrangement
- house marker/sign

Do not change:
- footprint
- doorway contract
- overall height range
- wall collision layout class

## Exterior materials

Reuse settlement language:
- timber
- stone base
- muted shingles
- limited plaster/wood infill if needed
- dark metal hardware

Residences should appear simpler/lighter than Community Hall.

## Interior reference

Show:
- one main living space
- partial/private rest zone
- bed/rest object
- simple table/storage
- clear center walking route

Avoid:
- multiple hallways
- several tiny rooms
- clutter-heavy domestic simulation

## Yard language

Possible sockets:
- woodpile
- stool/bench
- lantern
- low fence
- small storage
- limited garden/laundry detail

Yard must not dominate the facade.

## Modular breakdown

- foundation/base
- plain wall panel
- window wall panel
- door wall panel
- corner posts
- roof halves
- ridge
- optional awning
- optional chimney
- window/door frames

## Generation prompt specification

Create an original reusable compact frontier residence for a first-person pixel-styled real-3D RPG. Approximately 7 m wide by 5.5 m deep, one story, 3.2 m wall height, pitched roof around 5 m ridge, east-facing 1.6 m doorway, timber construction with stone base and muted shingles. Show two compatible visual variants using the same footprint and doorway contract: vary window placement, beam pattern, awning, small chimney, and yard props while preserving structural compatibility. Include front, side, rear, top/roof, 3/4, and a simple interior cutaway with one main room and small private/rest zone. Game asset reference sheet, modular parts clearly separated, restrained detail, neutral background, no watermark, original design.

## Review checklist

- same structural contract across variants
- doorway clearly readable
- compact enough for S03
- less visually dominant than Community Hall
- interior simple
- no fake unusable entrance language
