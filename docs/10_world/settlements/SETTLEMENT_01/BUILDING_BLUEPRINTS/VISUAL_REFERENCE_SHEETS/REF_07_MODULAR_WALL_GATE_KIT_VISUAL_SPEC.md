# Visual Reference Spec — Modular Wall and Gate Kit

Status: READY FOR REFERENCE GENERATION  
Blueprint:
`../MODULAR_WALL_GATE_KIT.md`

## Required modules

- 4 m straight wall
- 2 m straight wall
- inside corner
- outside corner
- left gate connector
- right gate connector
- watch connector
- gate post/frame
- optional utility opening

## Visual identity

Target:
- compact frontier defensive perimeter
- practical settlement construction
- modular repetition with controlled variation

Avoid:
- castle curtain wall
- giant stone fortification
- high fantasy battlements
- overly thin fence-only look

## Height

Visual range:
- about 4.5–6 m

## Materials

Preferred combination:
- timber palisade/beam system
- stone base/footing
- dark metal brackets
- cloth/banner sockets

## Connector requirement

Every module must visually expose compatible ends.

Reference sheet should clearly show:
- module length
- connection edge
- corner turning behavior
- gate-connector relationship

## Variation

Allowed:
- timber repair patch
- banner socket
- support-beam variation
- weathering/material variation

Not allowed:
- different collision width/height for arbitrary cosmetic variants

## Generation prompt specification

Create an original modular frontier settlement wall and gate construction kit for a first-person pixel-styled real-3D RPG. Show a 4 m straight wall, 2 m straight wall, inside corner, outside corner, left/right gate connectors, watch connector, gate post/frame and optional utility opening. Use sturdy timber defensive construction with stone footings, dark metal brackets and restrained banner sockets. Visual height around 4.5–6 m. The kit should feel protective but not like a castle, and every module should have clearly compatible connection edges. Show orthographic front/side/top and exploded modular pieces on a neutral reference sheet. Original IP, no watermark.

## Review checklist

- module compatibility readable
- gate connectors preserve 8 m opening
- not fortress-scale
- collision-friendly simple forms
- strong reusable silhouette
