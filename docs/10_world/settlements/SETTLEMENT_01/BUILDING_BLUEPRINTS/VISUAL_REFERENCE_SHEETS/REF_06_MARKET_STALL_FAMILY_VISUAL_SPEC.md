# Visual Reference Spec — Market Stall Family

Status: READY FOR REFERENCE GENERATION  
Building blueprint:
`../BLD_06_MARKET_STALL_VARIANTS.md`

## Base geometry

Target:
- 4×3 m footprint
- open front
- compact canopy
- minimal collision

## Variant requirement

Produce four compatible variants using one shared structural frame:

A. general goods / produce  
B. food/basic supply  
C. civic/local rotating vendor  
D. hunter/material/equipment display

## Visual identity

Target:
- readable from first person
- strong canopy/sign differences
- low detail
- no clutter blocking customer access

## Shared structure

- 4 corner/support posts or equivalent
- counter/table
- canopy
- sign socket
- display sockets

## Materials

- timber frame
- cloth canopy
- dark metal hardware
- reused crates/racks

## Generation prompt specification

Create an original modular market-stall family for a first-person pixel-styled real-3D RPG. All four variants use the same compact 4×3 m structural footprint and compatible collision: timber posts, simple counter, cloth canopy, sign socket and display sockets. Show four variants: produce/general goods, food/basic supplies, civic/local rotating vendor, and hunter/material/equipment display. Vary canopy color, sign shape, hanging/display props and counter arrangement while preserving the same structural frame. Keep clutter controlled and front access obvious. Show front/side/top/3-4 views and modular components on a neutral reference-sheet background. Original IP, no watermark.

## Review checklist

- same structural contract
- clear variant identity
- customer access open
- no excessive prop density
- reusable modules obvious
