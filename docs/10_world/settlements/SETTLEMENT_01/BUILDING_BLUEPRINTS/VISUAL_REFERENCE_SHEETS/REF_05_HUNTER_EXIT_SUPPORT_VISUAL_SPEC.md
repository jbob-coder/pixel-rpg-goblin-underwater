# Visual Reference Spec — Hunter Exit Support

Status: READY FOR REFERENCE GENERATION  
Building blueprint:
`../BLD_05_HUNTER_EXIT_SUPPORT.md`

## Scope

Covers:
- Hunter Watch
- Supply Cache
- North Hunter Gate support language

## Visual identity

Target:
- rugged hunt-departure threshold
- practical warning/preparation space
- visibly different from civilian South Gate
- compact and original

Avoid:
- fortress
- military base
- giant tower
- gothic gate
- copied Monster Hunter visual language

## Hunter Watch

Target:
- 7×7 m
- small enterable base
- visually elevated lookout identity
- optional non-traversable upper watch silhouette

Must support:
- Warden
- route/bounty board
- preparation anchor
- lookout

## Supply Cache

Target:
- 7×6 m
- simple storehouse
- visible racks/supply identity
- south/west facing entrance

## North Gate language

- 8 m clear passage
- rugged timber/stone
- warning banners/signs
- lanterns
- fence/wall transition
- clear trail beyond

## Material language

- darker/weathered timber
- stone footings
- dark metal
- rough cloth warnings
- restrained red/orange warning accent only if consistent

## Modular parts

- watch base
- lookout roof/cap
- supply-store walls
- gate post
- wall connector
- bounty board
- prep rack
- warning sign
- lantern mount

## Generation prompt specification

Create an original rugged hunter-exit reference sheet for a first-person pixel-styled real-3D RPG settlement. Include a compact 7×7 m Hunter Watch with a small enterable ground room and strong lookout silhouette, a 7×6 m Supply Cache with visible storage identity, and an 8 m-wide north gate passage leading directly to a forest/trail. Use weathered timber, stone footings, dark metal hardware, warning banners, bounty/route board, prep racks and lanterns. The area should feel like a dangerous hunt-departure threshold, distinct from a civilian arrival gate, but not a fortress and not copied from existing game IP. Show front/side/rear/top/3-4 views and modular parts. Neutral background, no watermark.

## Review checklist

- north gate remains visually open
- dangerous/departure identity clear
- watch readable without becoming giant tower
- supply cache clearly separate
- original IP
