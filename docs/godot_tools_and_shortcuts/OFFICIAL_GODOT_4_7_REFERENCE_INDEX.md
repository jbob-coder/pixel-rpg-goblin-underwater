## How another bot should use this index

When implementing:

1. inspect current repository code first;
2. locate the relevant domain above;
3. open the exact Godot 4.7 class/tutorial page;
4. verify method/property/signature;
5. implement the smallest safe change;
6. run the repository's parse/runtime tests;
7. never treat a feature being documented here as proof the project already uses it.

This index is a navigation aid, not a copied replacement for the Godot class reference.
