## Authority barrier

This directory preserves historical implementation, migration, verification, device, and continuation records.

A handoff does **not** become current Pixel RPG design, camera, visual, gameplay, runtime, or work-priority authority merely because it exists here or because its original build passed.

Current work begins from:

1. current explicit creator instruction;
2. live production `main`;
3. `START_HERE_NEW_CHAT.md`;
4. current repository map/master scan;
5. exact owning source/tests;
6. exact same-SHA build/device evidence;
7. current GitHub issue register.

The old `Chatgptjuegolpcal@pixel-rpg` repository/branch is migration/provenance history.

## What belongs here

- bounded implementation handoffs;
- exact old source/build evidence;
- migration/recovery records;
- package status snapshots;
- supersession records;
- device/probe evidence;
- historical camera/presentation checkpoints;
- domain implementation evidence;
- exact information needed to reconstruct what a past revision did.

## Preservation rule

Do not rewrite historical evidence to pretend an old build implemented a newer design.

Old third-person, aerial, Shooter-RPG, Stage-1 probe, or superseded branch evidence may remain here as truthful history.

When current source/tests still depend on a subsystem described by an old handoff, that handoff is **supporting technical provenance**, not present design authority.

## Classification rule

Use the classification index before opening handoffs broadly.

Categories are intentionally conservative:

- CURRENT-SUPPORTING TECHNICAL EVIDENCE;
- LIVE LEGACY-DOMAIN PROVENANCE;
- SUPERSEDED PRESENTATION / MIGRATION HISTORY;
- STAGE-1 PROBE / DEVICE HISTORY;
- DESIGN / FIRST-SLICE PROVENANCE.

Classification does not mean every sentence in a handoff is current.

## Verification language

Keep separate:

`source/readback ≠ static gate ≠ Godot parse ≠ headless/runtime gate ≠ APK build ≠ phone install ≠ phone runtime ≠ visual acceptance ≠ sustained performance`

No handoff may silently change current mechanics or override an owning live source/test/authority.
