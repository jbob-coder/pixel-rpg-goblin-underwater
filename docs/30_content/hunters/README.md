# Hunter Content Packages

Status: CONTENT-PACKAGE GUIDE
Last reconciled: 2026-09-02

## Purpose

Store hunter/player-character content definitions separately from generic gameplay rules and art-production references.

A hunter package may define:
- physical/body prototype;
- modular-equipment presentation requirements;
- rig/body compatibility targets;
- starting content assumptions when explicitly selected;
- reference-sheet requirements;
- links to gameplay systems.

It does not redefine:
- attribute formulas;
- equipment rules;
- combat economy;
- status/terrain systems;
- global model-art standards.

Those remain in their owning system authorities.
