# Monster Content Packages

Status: CONTENT-PACKAGE GUIDE
Last reconciled: 2026-09-02

## Purpose

Store species/monster-specific design packets without redefining global anatomy, behavior, crystal, mutation, stats/effects or region systems.

Each major monster package should eventually contain:
- species identity/body plan;
- habitat/region relationships;
- anatomy and functional capability map;
- break/sever/destroy interactions;
- crystal profile;
- mutation families;
- deterministic behavior phases/rules;
- attack roster requirements;
- harvest relationships;
- visual/model reference requirements;
- implementation/QA acceptance checklist.

Global rules remain in root owning authorities.
